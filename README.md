# Mongol Rebus

Монгол болон англи зурагт тааврын тоглоом. Ганцаараа эсвэл 2 багаар тоглоно.

- Тоглоом: `index.html` — таавруудыг `data/puzzles.json`-аас уншина, зургууд `images/` хавтсанд.
- Admin: `admin.html` — GitHub token-оор нэвтэрч таавар, багц нэмэх / засах / устгах. «Сайтад нийтлэх» дарахад нэг commit болж орно, GitHub Pages 1–2 минутад шинэчлэгдэнэ.

Хариултыг монгол, англи, латин үсгээр (жишээ нь `tsasan khun`) бичсэн ч зөв тооцно.
